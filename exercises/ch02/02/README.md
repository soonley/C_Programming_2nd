## Exercise 2.02
思考下面的程序： 
```c
#include <stdio.h> 
 
int main(void) 
{ 
  printf("Parkinson's Law:\nWork expands so as to "); 
  printf("fill the time\n"); 
  printf("available for its completion.\n"); 
  return 0; 
}
```
(a) 请指出程序中的指令和语句。 
(b) 程序的输出是什么？
## solution
(a) 一个指令（directive):`#include`, 四条语句(三个`printf`调用语句和一个`return`语句)
(b) 
Parkinson's Law:
Work expands so as to 
fill the time
available for its completion.
