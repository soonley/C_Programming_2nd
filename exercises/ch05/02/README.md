## Project 5.02
下列代码片段给出了逻辑运算符的示例。假设 i、j 和 k 都是 int 型变量，请给出每道题的输出
结果。 
(a) 
```
i = 10; j = 5; 
printf("%d", !i < j); 
```
(b) 
```
i = 2; j = 1; 
printf("%d", !!i + !j); 
```
(c) 
```
i = 5; j = 0; k = -5; 
printf("%d", i && j || k); 
```
(d) 
```
i = 1; j = 2; k = 3; 
printf("%d", i < j || k); 
```
## Solution
(a)
`1`
(b)
`1`
(c)
`1`
(d)
`1`
