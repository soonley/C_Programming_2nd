## Exercise 5.05
下面的 if语句在 C 语言中是否合法？
```
if (n >= 1 <= 10)
  printf("n is between 1 and 10\n");
```
如果合法，那么当 n等于 0 时会发生什么？
## Solution
关系运算符是左结合, `n >= 1`时输出`1`, `1 <= 10`表达式成立,`printf`被调用.因此在C语言中合法.
`n`等于`0`时`printf`依旧被调用.
> 虽然表达式合法,但是不能用于判断n是否在1到10之间, n>=1要么输出0,要么输出1, 该值≤10永远成立,因此不算n为何值,if语句都是成立的.
