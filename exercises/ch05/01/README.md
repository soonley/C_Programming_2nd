## Exercise 5.01
下列代码片段给出了关系运算符和判等运算符的示例。假设 i、j和 k都是 int型变量，请给出每道
题的输出结果。
(a)
```
i = 2; j = 3;
k = i * j == 6;
printf("%d", k);
```
(b) 
```
 i = 5; j = 10; k = 1;
 printf("%d", k > i < j);
```
(c)
```
i = 3; j = 2; k = 1;
printf("%d", i < j == j < k);
```
(d)
```
i = 3; j = 4; k = 5;
printf("%d", i % j + i < k);
```
## Solution
(a)
`k = 1`
(b)
`1`
(c)
`1`
(d)
`0`
