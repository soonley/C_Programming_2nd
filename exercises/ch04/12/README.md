## Exercise 4.12
给出下列程序片段的输出结果。假设 i和 j都是 int型变量。
(a) 
```
i = 5;
j = ++i * 3 – 2;
printf("%d %d", i, j);
```
(b)
```
i = 5;
j = 3 – 2 * i++;
printf("%d %d", i, j);
```
(c) 
```
i = 7;
j = 3 * i-- + 2;
printf("%d %d", i, j);
```
(d) 
```
i = 7;
j = 3 + --i * 2;
printf("%d %d", i, j);
```
## Solution
(a)
```
6 13
```
(b)
```
6 -7
```
(c)
```
6 23
```
(d)
```
6 15
```
